# USER_FLOW.md — 사용자 흐름

```
/ (메인)
  ├─ 피해 유형 카드 클릭 → 유형 저장 → /consultation
  ├─ 익명 상담 시작하기 → /consultation
  ├─ 신고서 초안 만들기 → /report-draft (입력 없이도 직접 작성 가능)
  └─ 피해자 지원기관 찾기 → /support

/consultation (5단계, 언제든 ‘이전’·‘상담 중단’)
  1. 안전 확인: 네 / 아니요 / 잘 모르겠어요
       └─ ‘네’ → 긴급 안내(112·1366, 안전 장소, 가해자 접촉 금지) 최우선 표시
  2. 피해 유형 선택(5종)
  3. 현재 상황 선택(6종, 건너뛰기 가능)
       └─ ‘협박을 받고 있음’ + 위험 ‘아니요’가 아닌 경우 → 긴급 안내 표시
  4. 상황 설명(10~2000자, 개인정보·영상 입력 금지 경고)
  5. 처리 방식 확인
       ├─ 서버 AI 미설정 → “데모 모드” 고지
       └─ 서버 AI 설정 → 외부 전송 동의 체크박스(미동의 시 데모)
  → POST /api/consultation → /result

/result
  ├─ 모드 배지(데모/실제 AI, 대체 사유)
  ├─ 긴급 위험이면 긴급 안내 재표시
  ├─ 공감 문구 · 안전 수준 · 요약 · 확인 필요 사항 · 권장 단계 · 공식기관 카드
  ├─ 신고서 초안 만들기 → /report-draft
  ├─ 증거 정리로 이동 → /evidence
  ├─ 결과 내용 복사
  └─ 처음으로(세션 초기화)

/evidence
  ├─ 기본 정보(발생·발견 일시, 플랫폼, URL, 메모)
  ├─ 자료 체크리스트(피해 유형별 우선 항목 배지, 확보/미확보, 메모)
  ├─ 증거 보존 주의사항 5개
  └─ 이 내용으로 신고서 초안 만들기 → /report-draft

/report-draft
  ├─ 요청하는 도움 입력 → 입력 내용으로 다시 생성
  ├─ 초안 textarea 직접 수정
  ├─ 복사 / 텍스트 파일 저장(사용자 클릭 시에만)
  └─ 신고·삭제 지원 기관 카드 (자동 제출 없음 명시)

/support
  ├─ 전체 기관 카드(출처·마지막 확인일)
  ├─ 익명 사전 상담 안내 + 정리할 내용 + 익명성 한계 고지
  └─ 삭제 지원 안내 + 준비사항 + 내가 정리한 URL·발견 일시

/privacy  수집 항목 · 서버 동작 · 한계 · 현재 AI 설정 상태
/settings 언어 · 동작 모드 · 입력 내용 모두 지우기
```

모든 화면 상단에 112 긴급 배너가 고정되며, 피해 유형을 선택하지 않아도 `/support`·`/privacy`에 접근할 수 있다.
